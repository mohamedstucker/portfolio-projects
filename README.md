# Portfolio Projects

This repository publishes Mohamed Senesie Tucker's finished static web projects through GitHub Pages.

## Add a finished project

1. Create a folder using a short project name, for example `calculator`.
2. Upload the project's `index.html`, CSS, JavaScript, and image assets into that folder.
3. Add the project details to `projects.json`.
4. Commit the changes to `main`.
5. GitHub Actions publishes the updated repository automatically.

Projects will be available at:

`https://mohamedstucker.github.io/portfolio-projects/FOLDER-NAME/`
